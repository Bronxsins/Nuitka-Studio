**Nuitka Studio**

A clean, user-friendly GUI frontend for [Nuitka](https://nuitka.net) that turns Python scripts into executable Windows apps. No terminal, no command-line flags, no deep compiler knowledge required.

### Key Features
- **Point-and-click compilation** Select your `.py` file and build an `.exe` with a few clicks
- **Smart automation** Automatically analyzes your script for required dependencies/plugins and detects ICO files to speed up the entire build process
- **Metadata editor** Set product name, version, company, copyright, icon, and more
- **Presets system** Save and load metadata + build configurations for reuse across projects

Perfect for developers who want the power of Nuitka without the command-line complexity.
