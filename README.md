A clean, modern GUI frontend for [Nuitka](https://nuitka.net) that turns Python scripts into polished executable Windows apps.  
No terminal. No command-line flags. Just a simple point and click.

---

### ✨ Key Features

- 🖱️ **Point-and-click compilation**  
  Select your `.py` file and build a ready-to-run `.exe` in just a few clicks

- 🤖 **Smart automation**  
  Automatically analyzes your script for required dependencies & plugins, and detects ICO files to speed up the entire build process

- 📝 **Metadata editor**  
  Easily set product name, version, company, copyright, icon, and more

- 💾 **Presets system**  
  Save and load complete metadata + build configurations for instant reuse across projects

Perfect for developers who want the full power of Nuitka without the complexity.
